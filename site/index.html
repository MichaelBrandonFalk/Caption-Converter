4. Install

Mac Install Help

  1. Download the Apple Silicon Mac zip and unzip it.
  2. Drag Caption Converter.app into Applications.
  3. Try opening it once.
  4. If macOS blocks it, go to System Settings > Privacy & Security and click Open Anyway.
  5. If needed, Control-click the app in Applications and choose Open.

These builds are unsigned, so some Macs will show a warning the first time. Apple’s current guidance for allowing an app is in Open a Mac app from an unknown developer.

Windows: unzip the download, then open Caption Converter.exe.

Linux Mint: double-click the .deb download, choose Install Package, then launch Caption Converter from the applications menu. This build is for 64-bit Linux Mint 21 and 22. To install from a terminal, run sudo apt install ./Caption-Converter-linux-mint-amd64.deb in your Downloads folder.
